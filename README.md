# DTU Pay 2.0 — Independent Rebuild

An independent educational project to rebuild and improve a token-based payment system using modern software engineering practices.

## Background

This project is inspired by the [*02267 Software Development of Web Services*](https://lifelonglearning.dtu.dk/en/compute/single-course/software-development-of-web-services/) course at the Technical University of Denmark (DTU).

The original DTU Pay system was developed as a team course project in 2024. This repository documents my independent rebuild and improvements, starting in 2026.

## Project Goals

- Implement customer and merchant account management.
- Support token-based payment authorization.
- Implement payment and refund workflows.
- Design and test failure and edge cases.
- Explore microservices and asynchronous communication.
- Improve system reliability, testing, and documentation.

## Planned Technology Stack

- Java
- Quarkus
- REST APIs
- JUnit 5 and Cucumber
- PostgreSQL
- RabbitMQ
- Docker and Docker Compose
- GitHub Actions
